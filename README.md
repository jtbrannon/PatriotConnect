# PatriotConnect  
PatriotConnect is a Java-based Android application to take a user's information and automatically fill out PDFs from a list of sources. This application was developed to assist veterans in applying
for benefits utilizing Apache PDFBox to automatically scan PDF contents and input relevant information. PatriotConnect drastically speeds up the benefits application process for veterans from 10-15 minutes to as short as
30 seconds (20-30x improvement). 

This project was developed in 24-hours as part of [CodeLinc 6.0](https://www.lincolnfinancial.com/public/aboutus/careers/studentandrecentgrads/codelinc) (2019).
